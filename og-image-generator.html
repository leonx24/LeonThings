📸 How to Generate OG Image

  1. Open this file (og-image-generator.html) in your browser
  2. Take a screenshot of the card above (1200x630px)
  3. Or use browser dev tools: Right click the card → Inspect → Screenshot node
  4. Save as og-image.png
  5. Place in public/og-image.png
  6. The index.html already references it!

Alternative: Use online tools like https://og-playground.vercel.app/ to generate programmatically.
